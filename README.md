# Agente de IA para FPS

Protótipo jogável em navegador de um FPS contra um bot com percepção, decisão e movimento. Implementação sem dependências externas e sem etapa de compilação.

## Executar

Requer Node.js 20 ou superior.

```bash
npm start
```

Acesse <http://127.0.0.1:3000> em um navegador moderno. Execute `npm test` para verificar os cenários da lógica.

## Controles

| Ação | Tecla |
|---|---|
| Mover | W, A, S, D |
| Mirar | Mouse |
| Atirar | Segurar clique esquerdo (Mouse 1) |
| Correr | Shift |
| Recarregar | R |
| Mostrar mapa e estado da IA | F3 ou botão DEBUG |
| Pausar | Esc |

Em dispositivos de toque, use o direcional e os botões na tela; arraste sobre a arena para mirar e segure ATIRAR para disparar continuamente.
